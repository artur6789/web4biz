# Archie Portfolio

The homepage is a React application built with Vite and GSAP. The supporting case-study and detail pages remain static HTML pages.

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Deploy the contents of `dist/` to a static host. Vite builds the React homepage and carries the existing static detail pages into the production output.
